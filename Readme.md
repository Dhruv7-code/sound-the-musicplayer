# **Sound the music player**

**Website**: https://sound-the-music-app.netlify.app

## A modern, minimal and fully responsive web-application supporting multiple scrren sizes let's you play different music tracks categrized in different playlist. You as a user can have full audio control. 

## This project is mainly focused on front-end fundamanetals, DOM manipulation and media handaling on the browser

### **Overview**
Sound is a very lightweight and super minimal applicaiton that allows users to **play, pause, skip and control audio tracks** on the web.
This project is built with major focus on web-based application development technologies.
Sound is a real-world based and fully interactive and responsive application. It supports multiple scrren-sizes works effortlessly on Laptops, Macs, Phones, Tablets and even Ipads.
This project was created to strengthn practical JavaScript skills.
This project uses multiple audio tracks, all the tracks used in this project are **Royalty Free** to neglect any legal and copyright isses that may occur.

## **Tech Stack:**
Sound is a minimal and a simple web-application so it is built on only 3 major technologies
1. **HTML5** - Used to give a basic structure to the website 
2. **CSS3** - Used to give layout, aesthetic UI colors and design that sound has and responsiveness
3. **JavaScript(ES6)** - For music playing functionalities, loading songs from different playlists

## **Features:**
- Play and Pause audio tracks
- See to a selected part of the song
- Control the volume level
- Move to next and previous songs in the playlist
- Change to variopus playlist options to listen to particular kind of music
- Show the songs available in current playlist
- Display currernt song, with the time in music and time left
- Responsive design for desktop and and many other devices
- Clean, minimal and easy user interface

## **How Sound works:**
Sound's web application structure is given by HTML5 and styling with CSS3. Sound uses JavaScript parimarily for the most of the functionalities. 
JavaScript listens for button events like pause, play and next to control the music functions.
The projet strucutre has different playlist support, JavaScript listens to change in playlist and uses API to fetch all the songs and show then to the user on the left hand side (for mobile users in the hamburguer nav).
With integration of JavaScript and HTML, the user can change songs and songs detials will be updated on the seekbar.
JavaScript also functions to listen to seek control, when the user wants to skip to a particular part of the audio, JavaScript handles that and updates the time information of song on the seekbar.

## **Usage:**
Sound soes not require any installation or any manual update from the user. Users can follow the website to the web application and start using it.

**Laptop users**
Sound has a very minimal and easy to understand UI.
Once you land on the website, you will see different options for playlists. Once you click on any playlist, on the left hand side you will see all the audio track options that the playlist consists.
You can pick any song and start playing.
You can play, pause, skip to the next song or change to the previous song using the buttons on the seekbar.
You can also change the volume level through volume bar in the seek bar.
Once you change the songs, you will see the updated song information on the seekbar.
You can also seek to part of the song by clicking to the particular part on the music duration seek bar, by clciking the time information about the song will also be updated on the seekbar.

**Mobile, tablet/ ipad users:**
By landing on the Sound's web page you will have multiple options of playlists to choose from.
Select your vibe by clicking on any playlists, the entire song list will be available for you on the left side of the screen or in the hamburguer menu bar if using smaller screen device.
You can play any songs from the playlist by clicking on the play icon for the song.
You can control the music playback by clicking pause, play and can even change to the next or previous song in the playlist.
For smaller devices like mobile phones, you will have to go in the menu to look for all the music in the playlist and pick any one.
You can also seek to part of the song by clicking to the particular part on the music duration seek bar, by clciking the time information about the song will also be updated on the seekbar.
You can also change the volume level through volume bar in the seek bar.
